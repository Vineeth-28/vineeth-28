## 🚀 About Me

Backend and DevOps engineer who owns the full path from **code to production**.

- 💻 **Backend:** I design REST/tRPC APIs in **Node.js, Express and TypeScript**, with **MongoDB** and **Redis** for storage and caching, **Socket.io** for real-time features, and input validation, structured logging and request tracing built in
- 🐳 **Containers:** I package and run services with **Docker** and I'm extending into **Kubernetes** (manifests, probes, HPA, Ingress)
- 🌍 **Infrastructure as Code:** I provision **AWS** with **Terraform** (VPC, ALB, ASG, RDS, Secrets Manager, S3), with nothing clicked together in a console
- ⚙️ **CI/CD:** I automate build → test → scan → deploy with **GitHub Actions** and **Jenkins**, with security scanning in every pipeline
- 🐧 **Linux:** Bash scripting, systemd, networking, permissions
- 🧠 Because I write the services *and* run the platforms, I build APIs that are easy to deploy, observe and scale

## ⭐ Start here (best 3 projects)

### 1. [URL Shortener API](https://github.com/Vineeth-28/ShortUrl-): backend
A backend-only service with validated **tRPC** procedures and compact **Base62** codes generated from an **atomic Redis counter**, so there are no collisions under concurrency. It uses Redis caching for fast redirects, request correlation IDs and structured **Winston** logging.
`TypeScript · Express · tRPC · MongoDB · Redis · Zod · Winston`

### 2. [CloudBoard](https://github.com/Vineeth-28/cloudboard): DevOps
A production-style delivery pipeline for a user-directory service. A `git push` triggers CI/CD and ends in a **monitored, logged, rolling-updated Kubernetes deployment**.
`Kubernetes · Docker · CI/CD · Monitoring`

### 3. [AWS Infrastructure with Terraform](https://github.com/Vineeth-28/Assignment): cloud
A full AWS stack (VPC, ALB, ASG, RDS, Secrets Manager, S3) defined as code and deployed through a **GitHub Actions** pipeline.
`Terraform · AWS · GitHub Actions`
